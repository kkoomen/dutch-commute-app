Reisinformatie API

Changelog 

        Deze API bevat alle reisinformatie bronnen voor de NS App.

        ## Rate limiting
        Externe, niet-betalende gebruikers zijn onderworpen aan een rate limit van **300 requests per 5 minuten** \
        Wanneer deze limiet wordt overschreden, retourneert de API een `429 Too Many Requests` response.

        ## Rate limiting
        External, non-paying users are subject to a rate limit of **300 requests per 5 minutes** \
        When this limit is exceeded, the API returns a `429 Too Many Requests` response.
